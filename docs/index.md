**2fip** (*2 File Panel*) is a keyboard-driven, dual-panel file manager for the
[COSMIC](https://system76.com/cosmic) desktop, inspired by Total Commander and
COSMIC Files. It shows two folders side by side, so copying and moving
files between them is one key away.

![The two panels of 2fip](assets/2fip.svg){: width="96" }

## Highlights

- **Two panels with tabs.** Each tab remembers its folder, history, sorting
  and view (list or grid). Drag a tab to the other panel to copy it there.
- **Classic function keys:** <kbd>F2</kbd> rename, <kbd>F3</kbd> view,
  <kbd>F4</kbd> edit, <kbd>F5</kbd> copy, <kbd>F6</kbd> move, <kbd>F7</kbd>
  new folder, <kbd>F8</kbd> delete, <kbd>F9</kbd> terminal.
- **Background operations** with progress, cancel and a "file already
  exists" question.
- **Servers:** browse SFTP, FTP and FTPS folders like local ones, and save
  connections with their passwords in the system keyring.
- **Find files**, a **quick filter**, **favorites**, **thumbnails**, **folder
  sizes** with a [Folder Size](folder-size.html) analyzer, **drag and drop**, **color themes** and several languages.
