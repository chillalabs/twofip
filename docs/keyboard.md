title: Keyboard shortcuts
---

2fip is made to be used with the keyboard. These shortcuts work in the active
panel unless a dialog or a side panel is open.

## Function keys

| Key | Action |
|---|---|
| <kbd>F1</kbd> | This help |
| <kbd>F2</kbd> or <kbd>Shift</kbd>+<kbd>F6</kbd> | Rename |
| <kbd>F3</kbd> | View in 2fip's [viewer](viewer.html) (files with an app of their own open there) |
| <kbd>Alt</kbd>+<kbd>F3</kbd> | Always the built-in viewer |
| <kbd>F4</kbd> | Edit (open in the text editor) |
| <kbd>Shift</kbd>+<kbd>F4</kbd> | New file, opened in the editor |
| <kbd>F5</kbd> | Copy to the other panel |
| <kbd>F6</kbd> | Move to the other panel |
| <kbd>F7</kbd> | New folder |
| <kbd>F8</kbd>, <kbd>Delete</kbd> | Move to the trash |
| <kbd>Shift</kbd>+<kbd>F8</kbd>, <kbd>Shift</kbd>+<kbd>Delete</kbd> | Delete permanently |
| <kbd>F9</kbd> | Open a terminal here |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | Quit |

## Moving around

| Key | Action |
|---|---|
| <kbd>Tab</kbd> | Switch to the other panel |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next item |
| <kbd>Home</kbd> / <kbd>End</kbd> | First / last item |
| <kbd>Enter</kbd> | Open the selected file or folder (archives open like folders) |
| <kbd>→</kbd> | Enter the selected folder |
| <kbd>Backspace</kbd>, <kbd>←</kbd> | Parent folder |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> | Back / forward |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Type a path |

## Selecting

| Key | Action |
|---|---|
| <kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Extend the selection by one |
| <kbd>Shift</kbd>+<kbd>Home</kbd> / <kbd>End</kbd> | Extend the selection to the first / last item |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Space</kbd> | Calculate the size of the selected folders |

## Clipboard and files

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> | Copy / cut |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste into the current folder |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | File details |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Show / hide hidden files |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Refresh both panels |
| <kbd>Alt</kbd>+<kbd>F5</kbd> | Pack the selection into an archive (in the other panel) |
| <kbd>Alt</kbd>+<kbd>F9</kbd> | Extract the selected archives (into the other panel) |

## Tabs, views and tools

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | New tab |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close tab |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous tab |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>Ctrl</kbd>+<kbd>2</kbd> | List / grid view |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Quick filter |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | [Quick View](viewer.html#quick-view) in the other panel |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find files |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Favorites |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Connect to a server |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |

## In dialogs and side panels

| Key | Action |
|---|---|
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous field or button |
| <kbd>Enter</kbd> | Confirm, or press the focused button |
| <kbd>Esc</kbd> | Cancel or close |
